Step 1: Setup AWS (30 mins)
   └─ Launch 3 EC2 instances (1 master + 2 workers, t3.medium)
   └─ Configure security groups
   └─ Setup SSH access

Step 2: Initialize Kubernetes (20 mins)
   └─ Install containerd on all nodes
   └─ Install kubeadm, kubelet, kubectl
   └─ kubeadm init on master
   └─ Install Flannel CNI
   └─ Join workers to cluster

Step 3: Build Images (30 mins)
   └─ ./build-and-push-images.sh <dockerhub-username>
   └─ ./update-k8s-images.sh <dockerhub-username>

Step 4: Deploy (15 mins)
   └─ Copy k8s/ directory to master
   └─ ./deploy-to-k8s.sh
   └─ ./seed-k8s-database.sh

Step 5: Access (5 mins)
   └─ Frontend: http://<worker-ip>:30000
   └─ API: http://<worker-ip>:30080/api

TOTAL TIME: ~2 hours
